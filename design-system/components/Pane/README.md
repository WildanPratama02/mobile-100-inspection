# Pane

A very light grey, rounded area that groups one part of a screen: the PO list column, the Top 5 area, the results box, the shoe-map pane.

**Use** one Pane per region; place Lists, StatRows and buttons inside it. Panes sit on the white app background with `space-3` gaps between them.

**Consumer provides:** `children`, `label` naming the region for screen readers.
