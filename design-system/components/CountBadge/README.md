# CountBadge

A round accent badge with a number: defects recorded in an area, a PO or an inspection.

**Use** on area pills (defects in the active inspection), on PO list items (defects in the open session) and next to the outbox entry in the header (waiting submissions).

**Consumer provides:** `value`; renders nothing for 0 or empty. Add `label` when the number alone is ambiguous to a screen reader ("3 defect").
