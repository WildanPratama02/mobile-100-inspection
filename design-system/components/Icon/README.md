# Icon

The eleven line icons of Mobile 100% Inspection, 24px grid, 2px stroke, drawn in the current text colour.

**Use** beside a word on buttons (BACK, HOME, UNDO, EXPORT, FOTO), as the chevron of fields and nav rows, and alone only for the gear and the add-PO + (give those buttons an accessible label).

**Consumer provides:** `name`, optional `size`, `label` when the icon stands alone and carries meaning.
