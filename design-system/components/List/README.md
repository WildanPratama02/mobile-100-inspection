# List

A rounded white container that holds rows: drill-down options, history, Top 5 Defect, the PO list, the outbox.

**Use** it wherever rows stack. Rows themselves stay square with a hairline between them; the List gives the group its `radius-lg` corners and clips the first and last row to them.

**Consumer provides:** the rows as `children`, optional `role` (for example `list`).
