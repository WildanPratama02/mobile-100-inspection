# POListItem

A PO in the Home PO list: the number in italic mono, model and destination below, and the open session's defect count.

**Use** one per PO on the tablet, in the left column (landscape) or a horizontal strip (portrait). The selected PO is `selected` (blue fill).

**Consumer provides:** `po` exactly as in `ALL_PO_MASTER` (leading zero and prefix kept), `sub`, `count` of defects in the open session, `live` text while an inspection is active ("Inspeksi berjalan · REWORK"), `selected`, `onClick`.
