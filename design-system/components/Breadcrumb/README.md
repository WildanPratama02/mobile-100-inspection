# Breadcrumb

The path of the drill-down above the list: area › sub-area › family. The current level is filled blue; earlier crumbs are tappable and go back to that level.

**Use** above the drill-down list, next to the inspection-type chip. Leave out a level that was skipped because it had one option.

**Consumer provides:** `items` (strings, or `{label, onClick}` for the tappable ones; the last is current).
